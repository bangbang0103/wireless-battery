# Provenance

> **Language / 语言**: **English** | [简体中文](README.zh-CN.md)

Record protocol sources, copied-code licenses and attribution separately from hardware verification. Include model, connection, OS, firmware when known, fixture names, verifier/date, and per-capability results.

A protocol document or captured response is not hardware verification of every capability. Synthetic examples must say so explicitly and cannot support a `verified` package.
