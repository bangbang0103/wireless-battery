# 协议来源与证据记录（Provenance）

> **Language / 语言**: [English](README.md) | **简体中文**

协议来源、复用代码许可证与署名说明必须与真实硬件验证记录分开保存。请尽可能记录设备型号、连接方式、操作系统、已知固件版本、关联 Fixture 文件名、验证人/日期以及按能力细分的验证结果。

协议文档或单次抓包响应并不等同于每项能力都经过硬件验证。合成示例必须明确标明，且永远不能支撑 `verified` 状态的设备包。
